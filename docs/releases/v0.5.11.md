# v0.5.11 — Gestion des catégories de la bibliothèque

- **LED Studio / Galerie** : nouvelle zone **Gérer les catégories** avec **+ Créer**, **Renommer** et **Supprimer**.
- Une catégorie peut exister sans image ou GIF et reste enregistrée après suppression de son dernier fichier.
- **Renommer** met à jour automatiquement la catégorie de toutes les créations concernées, sans modifier leurs pixels, le rythme des GIF ou la luminosité.
- **Supprimer** une catégorie conserve toutes les images et GIF : les créations sont simplement réaffectées à **Non classé**.
- **LED Player** : conserve son filtrage combiné par catégorie et par type, ainsi que le classement alphabétique.
- Le registre est stocké dans `/config/.storage/govee_led_control.gallery` avec les créations et se reconstitue automatiquement à partir des catégories existantes pour les installations v0.5.10 et antérieures.
- Tests de migration, persistance, renommage, suppression et interface Studio ajoutés.

**Installation :** mettre à jour l'intégration complète vers v0.5.11, redémarrer Home Assistant pour enregistrer la commande WebSocket, puis actualiser les tableaux de bord (Ctrl+F5).

Les essais automatisés ne remplacent pas une validation physique sur le matériel H70B3.
