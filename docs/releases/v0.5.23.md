# v0.5.23 — Outils Dessin compacts et Enregistrer sous la matrice

Amélioration de l'interface de **LED Studio** sur H70B3, sans modification des pixels, GIF ou catégories.

- Le bloc **DESSIN** adopte la même charte que **IMAGES**, avec **six boutons à icône** : décaler toute l'image à gauche, à droite, sélectionner une zone, annuler, gomme et effacer l'image.
- Tous les boutons conservent leurs infobulles et noms accessibles. La sélection et la gomme disposent d'un état actif reconnaissable ; le mode sélection conserve les quatre déplacements directionnels, également avec des icônes.
- Sur un navigateur PC lorsque LED Studio dispose d'au moins **1120 px** de largeur, le bloc **ENREGISTRER** passe sous la **matrice 20 × 26 dans la colonne centrale**. Il contient les champs *Nom*, *Catégorie* et *Enregistrer le GIF / l'image*.
- La colonne de gauche conserve la palette, la chronologie et les outils de dessin, la colonne de droite conserve la galerie.
- En présentation compacte/mobile, l'éditeur et la matrice s'empilent verticalement ; le formulaire suit toujours la matrice.
- Le formulaire est masqué quand aucune création n'est ouverte ; les données et le mécanisme de sauvegarde restent inchangés.
- Le clic droit pour gommer, l'historique Annuler, les déplacements rectangulaires, les durées et la palette RVB franche restent fonctionnels.
- Tests automatisés : structure HTML, icônes et accessibilité, position des colonnes, affichage du formulaire et disposition responsive.

**Installation** : mettre à jour HACS vers v0.5.23 puis rafraîchir le navigateur Home Assistant. Les tests automatisés sont exécutés sur GitHub ; vérification visuelle finale sur PC et Android après installation.
