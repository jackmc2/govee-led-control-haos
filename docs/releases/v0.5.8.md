# v0.5.8 — Ajout d'appareil H70B3 plus clair

Correction de la fenêtre **Ajouter un appareil** dans Home Assistant.

- Le message **« Aucun nouvel appareil H70B3 à ajouter »** remplace **« Aucune H70B3 détectée »** lorsque aucun nouveau rideau n'est proposé.
- Les H70B3 déjà configurés restent volontairement exclus de la liste pour éviter les doublons ; la ligne d'actualisation indique maintenant combien sont déjà configurés.
- L'option **« H6069 : configurer via LAN »** n'apparaît plus dans l'assistant d'ajout H70B3.
- L'ajout manuel d'un nouveau H70B3 reste disponible si la découverte Bluetooth échoue.

**Aucun changement** aux périphériques déjà configurés, aux entités, aux images, aux GIF ou à la galerie. La prise en charge H6069 existante reste intacte en interne.
