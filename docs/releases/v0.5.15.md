# v0.5.15 — Déplacer les images dans l'éditeur LED Studio

- **Décaler le dessin à gauche ou à droite** : deux boutons `← / →` déplacent les pixels de l'image sélectionnée d'une colonne (1 LED) dans la matrice H70B3 de **20 × 26 pixels**.
- Les colonnes découvertes sont remplies de noir ; aucun bouclage de pixels d'une ligne à l'autre et aucune interpolation.
- Les décalages s'appliquent aussi bien aux images fixes qu'aux images individuelles d'un GIF. Les autres images et les durées sont préservées.
- **Réordonner le GIF** : boutons « ← Reculer l'image » et « Avancer l'image → » pour échanger l'image sélectionnée avec sa voisine dans la chronologie.
- L'image déplacée reste sélectionnée, avec sa durée associée. Les boutons sont désactivés lorsqu'un déplacement est impossible.
- **Annuler** restaure aussi bien un décalage de pixels qu'un déplacement dans la chronologie.
- Modifications locales jusqu'à l'enregistrement ; aucune commande envoyée au rideau pendant l'édition.
- Tests automatisés : limites de matrice, absence de bouclage, durées, ordre des images, limites de séquence et annulation.

**Installation** : mettre à jour vers v0.5.15 depuis HACS, redémarrer Home Assistant si nécessaire et recharger le frontend. Les tests et validations CI sont exécutés sur GitHub ; vérification sur écran HAOS à effectuer après installation.
