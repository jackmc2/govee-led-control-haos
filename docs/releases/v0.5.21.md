# v0.5.21 — Palette RVB franche et gomme au clic droit

Deux améliorations de l'éditeur **LED Studio** du rideau H70B3 :

- **Grille d’édition violette #7857FF** : les séparations entre les 520 LED remplacent le gris graphite, sans modifier la couleur réelle des pixels ni les GIF enregistrés.
- **Palette de 12 couleurs franches** : rouge **#FF0000 (255,0,0)**, vert **#00FF00 (0,255,0)**, bleu **#0000FF (0,0,255)**, jaune, cyan, magenta, orange, vert citron, violet, rose, blanc et noir. Les nuances précédentes partiellement délavées ont été remplacées ; le rouge est désormais la couleur initiale.
- Les pastilles affichent leur nom et les **composantes RGB exactes au survol**, avec un libellé accessible.
- **Clic droit sur un pixel** de la matrice dans l'éditeur (PC) : efface immédiatement **ce pixel en noir**, sans activer le bouton « Gomme » ni changer la couleur sélectionnée.
- Le menu contextuel du navigateur est supprimé uniquement pour un clic droit sur un pixel actif. Les menus au clavier et appuis longs tactiles conservent leur comportement.
- Chaque effacement est **annulable** avec « Annuler » ; un pixel déjà noir ne génère pas de modification.
- L'effacement agit seulement sur l'image en cours (image fixe ou trame GIF), y compris lors de l'utilisation du mode sélection rectangulaire.
- Les couleurs et animations **déjà enregistrées** ne sont pas altérées ; la grille reste native **20 × 26**, sans interpolation ni redimensionnement.
- Tests automatisés sur les valeurs RGB, la sélection de couleurs, le clic droit, l'annulation, l'intégrité des autres trames et l'absence de commande matérielle.

**Installation** : mettre à jour vers **v0.5.21** dans HACS, puis recharger LED Studio. Les tests et validations CI sont exécutés sur GitHub ; validation visuelle souris sur HAOS à confirmer après installation.
