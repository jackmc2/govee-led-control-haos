# v0.5.13 — Miniatures GIF animées et catégories harmonisées

- **LED Studio** : la puce affiche désormais directement le nom de la catégorie (**Noël**, **Fêtes**, **Divers**, **Non classé**), sans préfixe « Catégorie : ».
- **LED Player** : les miniatures des GIF sont maintenant **animées localement** comme dans Studio, avec respect de la durée de chaque image et petite **puce GIF** en bas de l'aperçu.
- **LED Player** : suppression de la ligne technique « GIF · N images · H70B3 » / « Image · H70B3 » dans la liste des vignettes.
- **LED Player** : la catégorie est affichée directement sous le nom, dans un encadré violet identique à celui de Studio.
- Les animations locales s'arrêtent lorsque la page devient invisible ou que la carte est démontée ; leur minuterie ne contacte pas Home Assistant, n'envoie pas de trame Bluetooth et ne lance aucun transfert.
- Tri alphabétique, filtres de type et de catégorie, lecture GIF native du rideau, commandes LAN et galerie stockée dans Home Assistant sont préservés.

**Installation :** installer la v0.5.13 depuis HACS, redémarrer Home Assistant, puis recharger le navigateur (Ctrl+F5).

Tests automatiques JavaScript, Python, Hassfest et HACS exécutés dans GitHub Actions.
