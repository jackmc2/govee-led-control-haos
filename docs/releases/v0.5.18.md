# v0.5.18 — LED Studio sur trois colonnes en mode PC

Lorsque la **carte LED Studio** dispose d'au moins **1120 px de largeur** :
- **À gauche — Outils** : couleur, palette, luminosité, commandes GIF, durée et chronologie, opérations de dessin, enregistrement, motifs et import.
- **Au centre — Matrice LED** : éditeur pixel par pixel **20 × 26** (520 LED), indépendant des outils, avec sa grille graphite améliorée.
- **À droite — Galerie** : catégories et créations enregistrées, avec leurs miniatures.
- Les images fixes/GIF et toutes les fonctions existantes conservent leurs IDs, comportements, pixels et durées.
- Avant l'ouverture d'une création, les commandes « Importer ou créer » occupent la largeur de l'espace d'édition.
- En dessous de **1120 px**, on conserve les présentations adaptatives antérieures (deux colonnes ou empilement) ; le téléphone reste pris en charge.

## Dimensionnement Lovelace — Studio 3 colonnes + Player 1 colonne

Pour conserver **LED Player à droite, sur une colonne**, la vue Home Assistant doit disposer de **quatre colonnes** Lovelace au total (Studio en couvre trois). Exemple du **bloc de vue uniquement**, à appliquer dans l'éditeur de Home Assistant si souhaité :

```yaml
type: sections
title: Gowee
path: gowee
max_columns: 4
sections:
  - type: grid
    column_span: 3
    cards:
      - type: custom:govee-led-studio
        h70b3_transport_entity: sensor.salon_govee_h70b3_4148_volledige_controle_via
        grid_options:
          columns: full
  - type: grid
    column_span: 1
    cards:
      - type: custom:govee-led-player
        title: LED Player
        grid_options:
          columns: full
cards: []
```

**Important** : `jackmc2/home-assistant-context` est un export **unidirectionnel Home Assistant → GitHub**. La vue doit être modifiée dans Home Assistant ; aucun changement de cet export n'est déployé automatiquement.

**Installation** : installer v0.5.18 depuis HACS et recharger le frontend. Les tests automatisés de structure et les validations de l'intégration sont exécutés par GitHub Actions ; validation visuelle PC / Android à confirmer après installation.
